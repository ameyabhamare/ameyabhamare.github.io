Agentic RAG for Competitive Intelligence

Centene · 2024–present
System architecture
Analyst query→ LangGraph router→ Retrieval agent→ Reranker→ Generator + Explainer→ LLM-as-a-Judge→ Grounded answer / Low-confidence → Human review↺ Eval dataset

Problem

Finance and strategy teams needed fast, trustworthy answers from scattered competitive-intelligence data. In a regulated, finance-facing setting, one hallucinated number would undermine trust in the whole tool.

Engineering

  • Multi-agent LangGraph workflow that splits retrieval, reranking, generation, and explanation into separate agents
  • LLM-as-a-Judge that scores coverage and grounding on every response
  • Confidence-based routing sends weak answers to human reviewers, and their labels feed back into the eval set

Production impact

  • 3× reviewer throughput
  • A finance-aligned evaluation loop that improves the system with use
  • Grounding is checked before an answer reaches a stakeholder

Model Deployment & Evaluation Platform

Centene · 2024–present
System architecture
Market data (30+)→ Databricks jobs→ MLflow registry→ Production scoring→ n8n monitors: tracing · drift · calibration↺ Owner alerts

Problem

Quality Rating System models for 30+ markets were run through manual Excel workflows. Every refresh was slow and error-prone, and nobody could see when a model had drifted.

Engineering

  • Moved the models to versioned Databricks pipelines with an MLflow registry, end to end
  • Automated evaluation with n8n for tracing, drift detection, and calibration checks
  • Set org-wide Python packaging standards: CI/CD, git hooks, auto-tagged releases, auto-published docs

Production impact

  • 30+ markets running on production pipelines
  • 95% less manual effort, about 500 analyst hours saved per year
  • Internal packages (AI compliance review, auto-reporting) saving 250+ more hours per year

Generative Workload Simulator for Amazon S3

Amazon · 2023–24
System architecture
S3 request telemetry (271M)→ SARIMA (seasonality)+ Gaussian copula (dependencies)→ Synthetic workload generator→ Perf experiments

Problem

S3 teams needed realistic traffic for performance experiments, and replaying real production workloads wasn't an option because it would disrupt the service.

Engineering

  • Generative model that combines SARIMA temporal dynamics with Gaussian-copula dependency structure
  • Validated at production scale on 271M encoded time-series records

Production impact

  • 74% distributional similarity to production
  • 98% normalized frequency preservation
  • Performance experiments no longer need to touch production
